## A. 特定商取引法に基づく表記【公開必須・法令】

販売主体である**会社の情報**をご提供ください（制作担当者個人の情報は使用しません）。

- [ ] **販売業者**：運営会社の正式名称（例：株式会社○○）
- [ ] **運営責任者**：会社の代表者名 または EC運営責任者の氏名
- [ ] **所在地**：会社の郵便番号・住所
- [ ] **電話番号**：会社の電話番号
  - ※公開ページに番号を出さず「請求があれば遅滞なく開示」とする運用も可。どちらにするか
- [ ] **メールアドレス**：問い合わせ用（独自ドメイン推奨。後述 F も参照）
- [ ] **営業時間**（現状の仮：平日 10:00–17:00 で良いか）

## B. Shopify「ストアの詳細」連絡先の差し替え【要対応】

- [ ] 現在ストア設定の住所・電話・メールが**制作担当者個人のもの**になっているため、**会社情報へ差し替え**てよいか確認
  - ※ここは注文確認メールの送信元・請求先にも使われます

## C. 配送・送料【公開必須】

- [ ] **送料**：全国一律いくらか（または地域別か）
- [ ] **送料無料ライン**：いくら以上で無料にするか（設けない選択も可）
- [ ] **発送までの日数**（現状の仮：注文確認後3〜5営業日）
- [ ] **配送業者**（ヤマト / 佐川 / 日本郵便 など）
- [ ] クール便の要否（お米は通常常温で可か）

## D. 決済手段【要確定】

- [ ] **Shopify ペイメント（クレカ / Apple Pay / Google Pay / Shop Pay）でスタート**で良いか
- [ ] コンビニ払い・代金引換・後払い（Paidy 等）を入れるか
  - ※これらは別アプリ（KOMOJU / Paidy 等）導入が必要。入れる場合は手数料負担の方針も

## E. 商品情報【品質・食品表示に必要】

各商品（お試し1kg / ギフト300g / 家庭用5kg）について：

- [ ] **品種**（例：いやひこまい？）と**産地**（袋に「○○県産」とあるが正式表記）
- [ ] **精米日の扱い**（発送時精米か）／**賞味期限の目安**／**保存方法**
- [ ] **内容量**（白米/玄米の別）
- [ ] **おすすめの炊き方・合数の目安**（あれば）
- [ ] **価格は現状（1kg ¥3,800 / 300g ¥2,200 / 5kg ¥14,800）で確定か**
  - ※参考：「お試し1kg」が単価最高（¥3,800/kg）で、入口商品としては割高。意図通りか確認
- [ ] **在庫の有無・数量管理**の方針

## F. 写真・ブランド素材【品質に直結】

- [ ] **商品写真**：現状3商品すべて同一・低画質。商品ごとの写真＋炊き上がりカット等を提供可能か
- [ ] **ブランドストーリー文**（なぜこの米か、銀座店との関係など。掲載してよい実績があれば）
- [ ] **ロゴ・使用可能な店舗写真**の素材

## G. ドメイン・メール【信頼性】

- [ ] **独自ドメイン**（例：najilaboule.jp 等）の取得・接続を行うか

## H. その他ポリシー確認

- [ ] **プライバシーポリシー**：内容は整備済み。問い合わせ先メールのみ会社のものへ差し替え
