# 返金ポリシー (文言の控え)

> テーマのファイルではなく **ストアポリシー** (設定 > ポリシー > 返金ポリシー)。公開 URL: `/policies/refund-policy`。フッターのポリシー一覧に自動で並ぶ。
> 書き込みは CLI: `shopify store execute --store vuvwb5-6g.myshopify.com --allow-mutations --query 'mutation($p: ShopPolicyInput!) { shopPolicyUpdate(shopPolicy: $p) { shopPolicy { type } userErrors { message } } }' --variable-file <json>` (variables は `{"p": {"type": "REFUND_POLICY", "body": "<HTML>"}}`)。
> この控えは条文 (文言) の決定版。ストア側で書き換わる値は載せない (2026-09-26 ユーザー指示)。書き込むときは現在の本文を取得して変える部分だけ置き換える。
> 文言の最終決定: 2026-09-26。

## 文言の決め事

- **特定の商品名・プラン名・数量・販売期間・年月は書かない** (2026-09-25 ユーザー決定)
- キャンセル: 注文確定後は不可。**ただし予約販売の商品は出荷準備に入る前ならフォーム連絡で可** (2026-09-26 ユーザー決定。特商法の「ご注文のキャンセル」と同じ内容)。複数回配送の途中解約・返金不可はそのまま
- 不良品対応 (到着後 7 日以内・送料当店負担) は旧ドラフトを踏襲

## 本文 (HTML)

```html
<h3>お客様都合による返品・交換</h3>
<p>食品の性質上、お客様都合による返品・交換はお受けできません。</p>

<h3>不良品・誤配送の場合</h3>
<p>以下の場合は、商品到着後 7 日以内にお問い合わせフォームまたはメールにてご連絡ください。送料当店負担にて交換または返金いたします。</p>
<ul>
  <li>商品に汚損・破損があった場合</li>
  <li>ご注文内容と異なる商品が届いた場合</li>
  <li>配送中の事故により品質に問題があった場合</li>
</ul>

<h3>ご注文のキャンセル</h3>
<p>ご注文確定後のキャンセルはお受けできません。</p>
<p>ただし、予約販売の商品は、出荷準備に入る前であればお問い合わせフォームからのご連絡によりキャンセルを承ります。出荷準備開始後はお受けできません。</p>
<p>複数回に分けてお届けする商品は、全回分を一括でお支払いいただく商品のため、途中解約およびそれに伴う返金はお受けできません。</p>

<h3>返金方法</h3>
<p>返金はご注文時のお支払い方法(クレジットカード等)への返金にて行います。返金の反映時期はカード会社により異なります。</p>
```
