## 修正・確認メモ

- **🚨 販売主体は運営会社** … 販売業者・運営責任者・所在地・電話・メールはすべて**会社の情報**を記載。制作者個人の情報は不可。Shopify「ストアの詳細」も会社情報へ要差し替え。
- **`</p>` の破損を修正** … 旧テキストの「ご連絡いただければ…< /p>」に閉じタグが文字として表示されていた箇所を除去。
- **電話番号の扱い** … 実記載を基本としつつ、「請求があれば遅滞なく開示」の文言を追加（特商法上、連絡先は「遅滞なく提供する旨」を示せば省略可。実記載すればこの一文は削ってもよい）。
- **お支払い方法** … Shopify ペイメント（デフォルト）を有効化する想定で記載済み（クレカ各種 / Apple Pay / Google Pay / Shop Pay）。コンビニ払い・代引き・後払いは Shopify ペイメント非対応のため、採用する場合は別アプリ（KOMOJU / Paidy 等）導入のうえ本文に追記。**最終的に有効な手段と表記を一致**させること。
- **送料** … `[送料]` `[金額]` は事業上の決定事項。実値を記入。
