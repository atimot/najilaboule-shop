# 特定商取引法に基づく表記 (ストアポリシーの控え)

> テーマのファイルではなく **ストアポリシー** (設定 > ポリシー > 特定商取引法に基づく表記)。公開 URL: `/policies/legal-notice`。フッターのポリシー一覧に自動で並ぶ。
> 書き込みは CLI: `shopify store execute --store vuvwb5-6g.myshopify.com --allow-mutations --query 'mutation($p: ShopPolicyInput!) { shopPolicyUpdate(shopPolicy: $p) { shopPolicy { type } userErrors { message } } }' --variable-file <json>` (variables は `{"p": {"type": "LEGAL_NOTICE", "body": "<HTML>"}}`)。
> 最終更新: 2026-09-25。このファイルはストアの本文と同じ HTML を控えとして置いている。

## 要確認

- `[　]` の 4 か所 (運営責任者・郵便番号・住所・電話番号) は未記入。**未記入のまま公開は不可** (特商法の表示義務違反)
- メールアドレスは個人 Gmail のまま。会社のアドレスに差し替える
- お支払い方法の表記 (Shop Pay / Apple Pay / Google Pay) は、実際に有効な決済手段と一致させる
- 沖縄・離島の追加送料 1,000 円は本文に書いたが、Shopify の配送設定 (料金) は未設定
