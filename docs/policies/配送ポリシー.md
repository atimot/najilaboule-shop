# 配送ポリシー (ストアポリシーの控え)

> テーマのファイルではなく **ストアポリシー** (設定 > ポリシー > 配送ポリシー)。公開 URL: `/policies/shipping-policy`。フッターのポリシー一覧に自動で並ぶ。
> 書き込みは CLI: `shopify store execute --store vuvwb5-6g.myshopify.com --allow-mutations --query 'mutation($p: ShopPolicyInput!) { shopPolicyUpdate(shopPolicy: $p) { shopPolicy { type } userErrors { message } } }' --variable-file <json>` (variables は `{"p": {"type": "SHIPPING_POLICY", "body": "<HTML>"}}`)。
> 最終更新: 2026-09-26。このファイルはストアの本文と同じ HTML を控えとして置いている。

## 要確認

- **特定の商品名・プラン名・数量・販売期間・年月は書かない** (商品の追加・入れ替えのたびに更新しないため。2026-09-25 ユーザー決定)。商品固有の発送時期・支払い条件は商品ページに書き、ポリシーは「各商品ページに記載」で参照する
- 既定の発送時期「ご注文確定後 1 週間程度」は `2026年度販売計画.pdf` のレギュラープランの値。それ以外は各商品ページに委ねる
- 「お届け先の変更はフォームから。発送準備に入った分は変更できない場合がある」は Claude の仮置き。締切日を決めるなら追記する
- 配送業者・お届け日時指定は未定のため書いていない
- 追加送料は沖縄県のみ 1,200 円 (離島・一部地域は取らない。2026-09-26 ユーザー決定)。Shopify の配送設定にも同じ内容を登録済み

## 本文 (HTML)

```html
<h3>送料</h3>
<p>全国送料込み(商品価格に含まれます)。</p>
<p>※沖縄県へのお届けは、別途追加送料 1,200 円を申し受けます。</p>

<h3>発送時期</h3>
<p>ご注文確定後 1 週間程度で発送いたします。</p>
<p>発送時期やお届け回数が異なる商品(予約販売の商品、複数回に分けてお届けする商品など)は、各商品ページに記載の時期にお届けします。</p>
<p>※天候・交通事情・配送状況により遅延する場合がございます。</p>

<h3>お届け先の変更</h3>
<p>複数回に分けてお届けする商品のお届け先を変更したい場合は、お問い合わせフォームよりご連絡ください。発送準備に入っている分は変更できない場合がございます。</p>

<h3>ご不在・住所不備の場合</h3>
<p>以下のお客様都合による再送料・返送料はお客様のご負担となります。</p>
<ul>
  <li>ご住所のご記入不備</li>
  <li>長期ご不在による配送業者の保管期限切れ</li>
  <li>お受け取りの拒否</li>
</ul>
```
