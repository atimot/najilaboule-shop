# 配送ポリシー (文言の控え)

> テーマのファイルではなく **ストアポリシー** (設定 > ポリシー > 配送ポリシー)。公開 URL: `/policies/shipping-policy`。フッターのポリシー一覧に自動で並ぶ。
> 書き込みは CLI: `shopify store execute --store vuvwb5-6g.myshopify.com --allow-mutations --query 'mutation($p: ShopPolicyInput!) { shopPolicyUpdate(shopPolicy: $p) { shopPolicy { type } userErrors { message } } }' --variable-file <json>` (variables は `{"p": {"type": "SHIPPING_POLICY", "body": "<HTML>"}}`)。
> この控えは条文 (文言) の決定版。ストア側で書き換わる値は載せない (2026-09-26 ユーザー指示)。書き込むときは現在の本文を取得して変える部分だけ置き換える。
> 文言の最終決定: 2026-09-26。

## 文言の決め事

- **特定の商品名・プラン名・数量・販売期間・年月は書かない** (2026-09-25 ユーザー決定)。商品固有の発送時期は商品ページに書き、ポリシーは「各商品ページに記載」で参照する
- 発送時期は **商品ページが正**。記載が無い商品だけ「ご注文確定後 1 週間程度」(2026-09-26。特商法の「商品の引渡時期」と同文)
- 予約販売 (収穫時期に合わせてお届けする商品) は前払いで、商品ページに記載の時期からご注文順に発送
- 「お届け先の変更はフォームから。発送準備に入った分は変更できない場合がある」は Claude の仮置き。締切日を決めるなら追記する
- 配送業者・お届け日時指定は未定のため書いていない
- 送料は全国送料込み・沖縄県のみ +1,200 円 (税込)。「配送」の設定と一致させる

## 本文 (HTML)

```html
<h3>送料</h3>
<p>全国送料込み(商品価格に含まれます)。</p>
<p>※沖縄県へのお届けは、別途追加送料 1,200 円（税込）を申し受けます。</p>

<h3>発送時期</h3>
<p>各商品ページに記載の発送時期に発送いたします。</p>
<p>収穫時期に合わせてお届けする予約販売の商品は、ご注文時にお支払いいただき、商品ページに記載の時期からご注文順に発送いたします。発送時期の記載がない商品は、ご注文確定後 1 週間程度で発送いたします。</p>
<p>※天候・収穫状況・交通事情・配送状況により遅延する場合がございます。発送が大きく遅れる場合はメールにてご連絡いたします。</p>

<h3>お届け先の変更</h3>
<p>複数回に分けてお届けする商品のお届け先を変更したい場合は、お問い合わせフォームよりご連絡ください。発送準備に入っている分は変更できない場合がございます。</p>

<h3>ご不在・住所不備の場合</h3>
<p>以下のお客様都合による再送料・返送料はお客様のご負担となります。</p>
<ul>
  <li>ご住所のご記入不備</li>
  <li>長期ご不在による配送業者の保管期限切れ</li>
  <li>お受け取りの拒否</li>
</ul>
```
