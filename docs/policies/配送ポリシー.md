# 配送ポリシー (ストアポリシーの控え)

> テーマのファイルではなく **ストアポリシー** (設定 > ポリシー > 配送ポリシー)。公開 URL: `/policies/shipping-policy`。フッターのポリシー一覧に自動で並ぶ。
> 書き込みは CLI: `shopify store execute --store vuvwb5-6g.myshopify.com --allow-mutations --query 'mutation($p: ShopPolicyInput!) { shopPolicyUpdate(shopPolicy: $p) { shopPolicy { type } userErrors { message } } }' --variable-file <json>` (variables は `{"p": {"type": "SHIPPING_POLICY", "body": "<HTML>"}}`)。
> 最終更新: 2026-09-25。このファイルはストアの本文と同じ HTML を控えとして置いている。

## 要確認

- 発送時期は `2026年度販売計画.pdf` の値 (初回販売 12 月上旬〜、1 年契約 1 月上旬から毎月上旬、レギュラー 注文確定後 1 週間程度)
- 「お届け先の変更はフォームから。発送準備に入った分は変更できない場合がある」は Claude の仮置き。締切日を決めるなら追記する
- 配送業者・お届け日時指定は未定のため書いていない

## 本文 (HTML)

```html
<h3>送料</h3>
<p>全国送料込み(商品価格に含まれます)。</p>
<p>※沖縄・離島・一部地域へのお届けは、別途追加送料 1,000 円を申し受けます。</p>

<h3>発送時期</h3>
<ul>
  <li><strong>初回販売セット</strong>(新之助 5kg + きたりえカレー 2 個): 2026 年 12 月上旬より順次発送いたします。</li>
  <li><strong>新春セール・1 年契約</strong>(新之助 5kg × 12 袋): 2027 年 1 月上旬より、毎月上旬に 1 袋(5kg)ずつ、12 か月にわたってお届けします。</li>
  <li><strong>レギュラー</strong>(新之助 5kg): ご注文確定後 1 週間程度で発送いたします。</li>
</ul>
<p>※天候・交通事情・配送状況により遅延する場合がございます。</p>

<h3>お届け先の変更(1 年契約プラン)</h3>
<p>お届け先の変更をご希望の場合は、お問い合わせフォームよりご連絡ください。発送準備に入っている分は変更できない場合がございます。</p>

<h3>ご不在・住所不備の場合</h3>
<p>以下のお客様都合による再送料・返送料はお客様のご負担となります。</p>
<ul>
  <li>ご住所のご記入不備</li>
  <li>長期ご不在による配送業者の保管期限切れ</li>
  <li>お受け取りの拒否</li>
</ul>
```
